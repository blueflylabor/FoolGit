# 💡 FoolGit (傻瓜式定制 Git 助理)

> **极简、防呆、纯选择题交互。** 专为日常高频 Git 操作定制，告别繁琐冗长指令与臃肿 GUI 软件。

---

## 🌟 设计哲学

对于绝大多数日常开发者和初学者来说：
1. **不需要复杂的学术级指令**：日常 90% 的场景无非是「一键同步保存」、「拉取更新」、「看改动」、「撤销误改」和「切分支」。
2. **拒绝长指令输入**：像选择题一样，按数字或回车即可完成安全操作流程。
3. **出厂极度克制，扩展自由自选**：默认只展示最核心的 6 个原子操作；想用高级功能？在「功能库」中一键勾选追加，或者添加专属自定义 Git 命令。
4. **轻量与防呆**：遇到冲突或异常时，翻译成通俗易懂的中文引导，而不是冷冰冰的 Git 错误堆栈。

## 🚀 快速上手

### 1. 启动 FoolGit
FoolGit **完全基于 Python 3 标准库构建，零外部依赖**，直接在终端中运行：

```bash
# 在当前 Git 仓库中启动
./foolgit

# 或指定路径启动
./foolgit ~/projects/my-app
```

### 2. (推荐) 配置全局快捷命令
将 `foolgit` 软链接到系统路径，即可在任何目录下随时输入 `foolgit`：

```bash
sudo ln -sf $(pwd)/foolgit /usr/local/bin/foolgit
```

## 📋 功能全景

### 1. 出厂核心功能（默认开启）

| 编号 | 功能名称 | 适用场景 | 底层组合逻辑 |
| :---: | :--- | :--- | :--- |
| **`[1]`** | **一键保存并同步** *(推荐)* | 随手存盘、下班提交 | 自动拉取 ➔ 记录改动 (add -A) ➔ 提交版本 ➔ 推送远端 |
| **`[2]`** | **一键拉取最新代码** | 上班前同步同事改动 | 安全检测 ➔ 拉取远程分支 ➔ 智能冲突提醒 |
| **`[3]`** | **查看代码改动详情** | 查看本地改动了什么 | 清晰展示已暂存/未暂存/未跟踪文件与代码增删行数 |
| **`[4]`** | **后悔药 / 撤销改动** | 写乱了想恢复干净状态 | ① 放弃所有未提交修改 ② 撤回上次 commit (保留代码) ③ 放弃单文件修改 |
| **`[5]`** | **切换或新建分支** | 换个分支开发或切新特性 | 列出所有本地分支按数字秒切，或按 `n` 快速输入新名称创建 |
| **`[6]`** | **暂存保存 / 恢复改动** | 临时存盘、避免拉取冲突 | 一键暂存打包 (stash) ➔ 随时一键弹出取回 (pop) |

---

### 2. 备选功能库（进入 `[+]` 随时一键勾选启用）

- **查看简明提交历史**：按时间倒序列出最近 10 次提交、作者与相对时间。
- **查看具体代码差异 (diff)**：逐行高亮展示工作区修改内容。
- **清理未跟踪垃圾文件**：一键清理本地新建但未追踪的临时杂质文件与空目录。
- **版本标签 (Release Tag)**：给当前版本打上 Release 标签并可一键同步推送到远端。
- **查看远程仓库地址**：快速检查当前仓库关联的 origin 远端地址。
- **多仓库批量巡检与同步**：继承 `gsyn` 核心能力，扫描子目录下所有 Git 项目并进行批量同步。

---

### 3. 自定义专属命令（Custom Commands）

在主菜单按 `[+]` 进入个性化设置，可随意添加你团队或个人专属的命令，例如：
- 显示名称：`发布Release标签`
- 执行命令：`git push origin --tags`
- 一经添加，会自动出现在主菜单的选项列表中！

## 🏗️ 架构与未来演进

```
FoolGit/
├── foolgit                 # 命令行可执行入口 (CLI)
├── foolgit_pkg/
│   ├── core.py             # Git 底层封装、执行引擎、错误翻译器 (与视图解耦)
│   ├── config.py           # 配置管理器 (~/.foolgit/config.json)
│   ├── presets.py          # 预设功能库元数据
│   └── cli.py              # 极简终端交互 UI
└── gsyn                    # 原版参考脚本
```

- **第一阶段（已完成）**：极简 CLI 终端交互、出厂傻瓜预设、备选功能库开关、自定义命令、多仓库支持。
- **第二阶段（规划中）**：基于 `core.py` 核心引擎，开发极简 GUI 桌面版（保持相同的克制风格：控制面板小挂件，大按钮直选，不做臃肿复杂提交树）。
